# 🚗 Car Dealership Inventory System

A full-stack web application for managing a car dealership inventory.

## 📌 Features

- User Registration
- User Login (JWT Authentication)
- Dashboard
- View Vehicles
- Add Vehicle
- Edit Vehicle
- Delete Vehicle
- Responsive UI

---

## 🛠 Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL

### Authentication
- JWT (JSON Web Token)

## ⚙ Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Backend

```bash
cd backend
npm install
```

Create `.env`

```env
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
```

Run Backend

```bash
npm run dev
```

---

### Frontend

```bash
cd frontend
npm install
npm run dev
```
